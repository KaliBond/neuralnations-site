🧮 Core Mathematics

Entropy Rate Dynamics

dS/dt = ε·(S_max - S) - ζ·C + γ·(1/K) - δ·A

Entropy accumulates under low coherence and capacity, and dissipates as abstraction increases. Constants: ε=0.20, ζ=0.18, γ=0.15, δ=0.12.

System Health Calculation

H' = (Σ(C_i · K_i) / 8) / 100

Normalized system health based on coherence-capacity products.

Stress Normalization

S̄' = S̄ / 10

Maps stress from [0, 10] to [0, 1] range for normalized calculations.

💻 Implementation

Quick Start Example

from cams_framework_v2_1 import CAMSNetwork, CAMSDataProcessor

# Load and process data
processor = CAMSDataProcessor()
df = processor.load_society_data("data/cleaned/USA_cleaned.csv")

# Create network for specific year
network = processor.create_network_from_year(df, 2025)

# Calculate key metrics
psi = network.compute_psi_metric()
health = network.compute_system_health()
classification = network.classify_system_type()

print(f"Ψ: {psi:.3f}")
print(f"Health: {health:.3f}")
print(f"Type: {classification}")
