🔬 CAMS Analysis Tools

Interactive Dashboard for Advanced Institutional Analysis

🚀 Launch Advanced Analysis Dashboard →

📊 dDIG Analysis

Directed Information Gain - Measure institutional influence through conditional mutual information.

  • Causal Influence Ranking: Identify which nodes drive system change
  • Context Control: Account for regime type, shock intensity, and era
  • Information Transfer: Quantify predictive power in bits
  • Normalized Metrics: nDIG scores for cross-society comparison

Use Case: Identify which institutions (Executive, Army, Priests, etc.) have the most predictive influence on system-wide dynamics.

🌀 Dyad Field Analysis

M-Y Dynamics - Track the tension between metabolic stress and mythic coherence.

  • M (Metabolic Load): Stress in material subsystem (Hands, Flow, Shield)
  • Y (Mythic Integration): Coherence in meaning subsystem (Lore, Archive, Stewards)
  • D (Mismatch): M - Y tension indicator
  • R (Risk): Crisis potential from coupling weakness

Use Case: Monitor the balance between material capacity and ideological coherence. High mismatch (D) with weak coupling (low B) signals instability.

🌌 Phase-Space Attractor

3D Trajectory Visualization - See institutional dynamics as trajectories through M-Y-B space.

  • Attractor Basins: Identify stable equilibrium regions
  • Regime Detection: K-means clustering reveals distinct stability regimes
  • Transition Dynamics: Track rapid shifts between regimes
  • Phase Velocity: Measure speed of institutional change
  • 2D Fallback Mode: Works even without Bond Strength data

Use Case: Visualize long-term system behavior. Tight spirals = stability, linear paths = directional change, jumps = shocks/crises.

📈 Combined Insights

Multi-Metric Analysis - Unified influence rankings across all CAMS metrics.

  • Cognitive Influence: Average of Coherence, Capacity, Abstraction nDIG
  • Affective Influence: Stress-based nDIG scores
  • Composite Rankings: Weighted influence scores per institution
  • Heatmap Visualization: Per-metric nDIG across all nodes

Use Case: Get a holistic view of which institutions matter most across multiple dimensions.

🎯 How to Use the Dashboard

  1. Click "Launch Advanced Analysis Dashboard" above
  2. Select a dataset from the sidebar (50+ societies available) or upload your own CSV
  3. Navigate between tabs:
    • 📊 dDIG Analysis - Configure quantile bins and click "Compute dDIG"
    • 🌀 Dyad Field Analysis - View M-Y dynamics and phase space
    • 📈 Combined Insights - Click "Compute Full Influence Bundle"
    • 🌌 Phase-Space Attractor - Adjust smoothing, detect regimes
  4. Export results as JSON for further analysis

📦 Dataset Format

The dashboard expects CAMS long-format CSV files with these columns:

Society, Year, Node, Coherence, Capacity, Stress, Abstraction, Bond Strength (optional)

Example:
USA, 2025, Executive, 5, 6, 3, 7, 2.1
USA, 2025, Army, 5, 7, 2, 6, 2.2
USA, 2025, Priests, 7, 8, 1, 8, 2.8
...

Supported Nodes: Auto-detects any node names (Executive, Army, Priests, Property, Trades, Proletariat, StateMemory, Merchants, etc.)

Time Range: Minimum 2 years, recommended 50+ years for robust dDIG analysis
